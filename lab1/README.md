# Lab 1: Introduction to Linux and Operating System Fundamentals

## 1. Introduction

This laboratory exercise introduces the basic concepts of Linux and operating systems. The practical work focuses on using the Linux terminal, understanding basic file and directory operations, and observing how commands interact with the operating system. The exercises provide practical experience with the Linux environment and basic system-level operations.

## 2. Objectives

The objectives of this laboratory are:

- To become familiar with the Linux terminal.
- To understand basic Linux commands and their functions.
- To create, view, copy, move, and manage files and directories.
- To understand the basic interaction between users, programs, and the operating system.
- To develop confidence in using the Linux command line.

## 3. Tools and Technologies

- Ubuntu Linux
- Linux Terminal
- GCC Compiler
- C Programming Language

## 4. Practical Work

The practical activities involved working with the Linux terminal and performing basic operating system-related operations. Different commands were executed to manage files, directories, and programs. C programs were also compiled and executed using GCC where required.

## 5. Key Observations

The practical demonstrated that Linux provides command-line tools for managing files, executing programs, and interacting with system resources. The exercises also provided an introduction to how programs are compiled and executed within the operating system.

## 6. Conclusion

This laboratory provided a basic understanding of the Linux environment and operating system interaction. The practical experience with terminal commands and program execution helped establish the foundation required for later system-level programming exercises.
